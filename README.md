# Booth Courses

Coursework for my time at Chicago Booth. Everything lives on `main`, with one folder per quarter and one subfolder per course.

## Layout

```
booth/
├── 2026-autumn/
│   └── <course-name>/
│       ├── notes/
│       ├── assignments/
│       ├── readings/
│       └── CLAUDE.md
├── 2027-winter/
│   └── ...
└── ...
```

Quarter folders are named `YYYY-season` (`autumn`, `winter`, `spring`, `summer`) so they sort chronologically.
